# SSL/TLS Server scanner
Utility to scan remote server for SSL/TLS security issues.

# Quickstart

  - Download [this archive](https://github.com/ondrejsmetak/ssl-tls-server-scanner/raw/master/scanner.zip) and unzip it.
  - Then consult following [user manual](https://github.com/ondrejsmetak/ssl-tls-server-scanner/blob/master/manual.pdf).

# More info
  - You can read [this chapter](https://github.com/ondrejsmetak/ssl-tls-server-scanner/blob/master/info.pdf) of my thesis, which is focused on automated testing of SSL/TLS communication.
  - You may be also interested in [SSL/TLS Client scanner](https://github.com/ondrejsmetak/ssl-tls-client-scanner).
